# Agri Compta

Application de gestion comptable agricole pour suivre les campagnes, parcelles, cultures, recoltes, depenses, recettes, stocks, mouvements de stock et rapports.

## Structure

- `agri-compta-backend/` : API Spring Boot.
- `agri-compta-frontend/` : interface Angular.
- `Document/` : documents de memoire et livrables.

## Commandes utiles

Backend :

```bash
cd agri-compta-backend
./gradlew test
./gradlew bootRun
```

Frontend :

```bash
cd agri-compta-frontend
npm install
npm run build
npm start
```
